أعمدة الملف المدعومة
العمود الوصف إلزامي يُحدَّث
item_id معرّف الصنف — أعلى أولوية للمطابقة (من ملف التصدير) لا للمطابقة فقط
item_name_ar / الصنف اسم الصنف بالعربية للجديد نعم
item_name_en / name_en اسم الصنف بالإنجليزية لا نعم
item_code / الكود كود الصنف — أولوية ثانية للمطابقة لا إن فارغ
unit_name / الوحدة الوحدة الأساسية للتخزين للجديد نعم
category_name / الفئة اسم الفئة (يجب أن تكون موجودة) لا نعم
min_level / الحد الأدنى الحد الأدنى للكمية لا نعم
notes / ملاحظة التغليف وصف التغليف — يظهر للموظفين لا نعم
is_active حالة الصنف — 1 نشط، 0 معطّل لا نعم
created_at تاريخ الإنشاء — للقراءة فقط، يُتجاهل عند الاستيراد لا للقراءة
الوحدة2/المعامل2 وحدات تحويل إضافية (2، 3، 4) لا نعم
