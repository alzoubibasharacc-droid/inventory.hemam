# Hamam Restaurants Inventory System

## Project Overview
A web-based inventory management and counting system for Hamam Restaurants using Python Flask.

## Branches

### Grand Branch
- Bakery
- Barista
- Warehouse
- Kitchen

### Main Branch
- Warehouse
- Kitchen

### Hashemi Branch
- Warehouse
- Kitchen

## Requirements
- Arabic UI
- Simple design for employees
- Login system
- Monthly inventory counting
- Unit conversion system
- Reports and dashboard

## Technologies
- Python Flask
- SQLite or PostgreSQL
- HTML/CSS/JavaScript
